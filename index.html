AI Music Genre Classification Project (Python)

In this project, I collaborated with a student to develop an AI model that classifies music genres. The core objective was to create a machine learning system capable of identifying music genres by analyzing audio samples.

• AI Training: We utilized a collection of labeled audio files to train the model, focusing on extracting relevant features from the audio. These features were used to teach the AI to differentiate between various music genres, such as pop, jazz, rock, and classical. We employed Python for data manipulation and machine learning tasks.

• Feature Extraction: We used the python_speech_features library to extract Mel-Frequency Cepstral Coefficients (MFCC) from the audio files. MFCC is a standard feature in speech and audio processing, helping the model understand the audio’s underlying characteristics.

• Machine Learning: The AI model was built using the K-Nearest Neighbors (KNN) algorithm, which classifies music based on its similarity to other samples. We trained the model using a dataset of audio samples and fine-tuned it for better performance.
